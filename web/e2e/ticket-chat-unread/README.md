# Браузерная проверка индикатора 💬 непрочитанного чата

В отличие от `e2e/ticket-nav`, моков нет: нужен живой backend и база,
потому что проверяется доставка по WebSocket и хранение отметки
прочтения. В CI набор не входит: playwright не числится в зависимостях web.

Что проверяется (24 проверки):

- 💬 появляется без перезагрузки на компьютере (`/board`) и на телефоне
  (`/m`, `/m/chats`) после чужого сообщения; у автора его нет;
- чтение на вкладке «Чат» мобильной карточки гасит 💬 в списке и на
  компьютере того же пользователя (сообщение `chat.read`), и наоборот;
- в «Чатах» значок виден и на свёрнутой строке объекта;
- скрытая вкладка браузера сообщение прочитанным не отмечает, а при
  возврате во вкладку отмечает;
- ошибок страницы нет.

Запуск (локальная одноразовая база, Stage и Production не трогать):

```sh
# backend на :3399, CORS для vite на :5398, база с применёнными миграциями
IDS=$(TAG=qa DATABASE_URL=… node web/e2e/ticket-chat-unread/seed.cjs)
(cd web && npx vite --port 5398 --strictPort) &
TAG=qa node web/e2e/ticket-chat-unread/run.cjs <путь>/playwright-core $IDS
```

Роль CLIENT управленческой части на компьютере не имеет, поэтому
читатель — ADMIN клиента (компьютер и телефон), автор — CLIENT.
Адреса меняются через `CHAT_API`, `CHAT_WEB`, снимки — `CHAT_SHOTS`.
Вход ограничен по частоте: для повторных прогонов поднять
`LOGIN_RATE_LIMIT_MAX_ATTEMPTS` у локального backend.
