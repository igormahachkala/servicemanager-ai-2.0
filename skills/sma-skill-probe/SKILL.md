# Проверка обнаружения скилов

Скилл существует только для диагностики. Никаких изменений в репозитории
он не производит.

## Что сделать

1. Сообщить маркер срабатывания: `SKILL-PROBE-OK`.

2. Сообщить полный путь файла, из которого прочитаны эти инструкции.
   Это отвечает на первый вопрос диагностики — из какого места скилл
   был подхвачен.

3. Прочитать файл `skills/_shared/probe-external.md` от корня репозитория
   и сообщить маркер, который в нём записан.

   Файл лежит вне каталога этого скила и попадает в репозиторий, поэтому
   проверка воспроизводится на любой машине. Если маркер из него прочитан
   и выведен, значит агент переходит по ссылке за пределы каталога скила —
   это второй вопрос диагностики. От ответа зависит, можно ли держать общий
   файл правил один раз и ссылаться на него из нескольких скилов, или его
   придётся копировать в каждый.

## Формат ответа

Три строки:

```
Маркер срабатывания: <маркер из пункта 1>
Прочитано из: <полный путь файла>
Внешний файл: <маркер из пункта 3, либо «не прочитан» с причиной>
```
