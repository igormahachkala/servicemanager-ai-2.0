# 0. Главный принцип работы

## 0.1 Правка файлов

Любые изменения в файлах делаем **полной заменой файла**, а не частичными вставками.

Процесс:

1. Находим файл (grep / sed / cat).
2. Печатаем файл полностью в чат.
3. Получаем полный новый контент.
4. Заменяем файл одной командой:

```bash
cat > path/to/file.ts <<'EOF'
...полный новый файл...
EOF
