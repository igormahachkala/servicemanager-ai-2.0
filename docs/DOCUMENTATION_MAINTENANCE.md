# DOCUMENTATION MAINTENANCE — ServiceManager.AI

Статус: Active  
Назначение: предотвратить устаревание документации.

Этот файл определяет **когда и какие документы должны обновляться**.

Документация является частью системы и должна поддерживаться так же,
как и код.

---

# 1. Главное правило

Если изменяется:

- API
- роли
- permissions
- schema.prisma
- архитектура
- бизнес-правила

→ **соответствующий документ обязан быть обновлён в том же PR.**

# 13. Проверка документации (ежемесячная)

Раз в месяц выполняется проверка:

1. Открыть папку docs/
2. Просмотреть каждый файл
3. Проверить соответствие коду
4. Обновить устаревшие части

---
