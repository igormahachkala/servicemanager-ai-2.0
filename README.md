# ServiceManager.AI — Mobile UX V2 (прототип)

Чистый прототип на базе Figma-эталона (`App.tsx`). Добавлен экран входа,
нижнее меню — 5 вкладок (Главная · Обходы · Создать · Чаты · Аналитика).
Выдуманных экранов нет. Данные — моки (это прототип-спецификация).

## Запуск
```bash
npm install
npm run dev
```
Открыть адрес из консоли (обычно http://localhost:5173).

## Сборка
```bash
npm run build && npm run preview
```

## Что внутри
- `src/app/App.tsx` — весь прототип (экраны, навигация, Вход).
- `src/styles/` — дизайн-токены (theme.css) и шрифты.
- Вход: почта + пароль, мок-авторизация (любые непустые поля → вход).

Стек: React 18 + Vite + Tailwind v4.
